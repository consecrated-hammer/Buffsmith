# Buffsmith

Buffsmith is a World of Warcraft addon for **out-of-combat** self-buffs and bag-discovered consumables on Forever and Retail.

It provides a movable self-buff bar, Food, Scroll, Flask and weapon-enhancement discovery, a preferred primary consumable with vertically expanding alternatives, a diagnostic copy report and an About entry.

Buttons directly apply their displayed self-buff or bag item while out of combat. Buffsmith is independently implemented.

Use `/buffsmith` for settings and `/buffsmith debug` for the selectable diagnostic report.
